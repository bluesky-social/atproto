# @atproto/lex-rpc

- [Changelog](./CHANGELOG.md)
- [`@atproto/lex` documentation](https://github.com/bluesky-social/atproto/blob/main/packages/lex/lex/README.md)

Type-safe HTTP ([XRPC](https://atproto.com/specs/xrpc)) utilities for Lexicon-defined APIs: exposes low-level `xrpc()` / `xrpcSafe()` functions for making requests based on Lexicon derived schemas.
